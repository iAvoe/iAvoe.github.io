## OneColumnEncoder 次时代视频压制工具（1cenc）

一款智能化、自动化、参与操作流程，带领新手入门高级视频压制的图形化 UI/UX 软件。支持自动生成多种视频滤镜与音视频编码参数、VS/AVS 脚本编辑、压制参数 UI 控制与实时 A/B 预览、可编辑压制队列、现代多线程控制、现代进度监视器等强大功能的压制软件，支持多种语言和原生中文。
